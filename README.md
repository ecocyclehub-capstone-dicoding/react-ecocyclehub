# EcoCycle Hub API

EcoCycle Hub API adalah backend REST API berbasis Django REST Framework untuk aplikasi pengelolaan sampah daur ulang. API ini mendukung autentikasi JWT, manajemen user berbasis role, kategori sampah, transaksi setoran sampah, saldo, poin, leaderboard, level gamification, dan dashboard untuk customer, officer, serta admin.

Repository ini disiapkan untuk berjalan sebagai **Hugging Face Docker Space**. Konfigurasi Space berada pada YAML front matter di bagian paling atas file ini.
